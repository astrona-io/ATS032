# ATS032 — CKS: Cluster Hardening

Preparation for the **Cluster Hardening** domain of **Certified Kubernetes Security Specialist (CKS)**.
The published domain weight is **15%**. This repository belongs to
the [ATP007 training path](https://github.com/astrona-io/ATP007).

**Status:** Preparation scaffold; content authoring has not started.
