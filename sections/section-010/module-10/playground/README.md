# Minimize Exposure With Role Based Access Control Playground

Author notes for the ungraded playground `ats-032-playground-010-01`. The learner guide is `docs/overview.md`.

- `bootstrap/setup.sh` applies `bootstrap/manifests/start.yaml`, the starting state that the module pages describe, and checks that it took effect.
- The playground has no grader, no reference solution and no smoke test. CI checks that `astrona run` finishes; the graded tasks of the module are separate labs under `labs/`.
